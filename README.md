# PR4 – Advanced Linear Algebra

## 📌 Project Overview
This project focuses on practical implementation of Advanced Linear Algebra concepts using Python. It demonstrates vector operations, matrix calculations, linear transformations, dimensionality, and eigenvalue decomposition with the help of a student marks dataset.

## 🎯 Objectives
- Represent student subject scores as vectors.
- Perform vector norm, dot product, and cross product operations.
- Understand and perform different matrix operations.
- Apply linear transformations in 2D and 3D.
- Understand dimensionality and hyperplanes.
- Calculate eigenvalues and eigenvectors of a covariance matrix.

## 🛠️ Tools & Technologies
- **Python**
- **Jupyter Notebook**
- **NumPy**
- **Pandas**

## 📚 Project Contents

### Part A: Vector & Matrix Fundamentals
1. Represent each student's subject scores as a vector.
2. Compute L1 Norm and L2 Norm.
3. Calculate the Dot Product of two student score vectors.
4. Calculate the Cross Product of two 3D vectors.

### Part B: Matrix Operations
5. Create a Students × Subjects matrix.
6. Perform Matrix Addition.
7. Perform Matrix Multiplication.
8. Calculate the Transpose of a Matrix.
9. Calculate the Inverse of a square matrix.
10. Calculate the Determinant of a matrix.

### Part C: Linear Transformations & Geometry
11. Understand Line, Plane, and Hyperplane.
12. Perform 2D Linear Transformation.
13. Perform 3D Linear Transformation.
14. Understand dimensionality changes from 2D to 3D and higher dimensions.

### Part D: Eigenvalues & Decomposition
15. Calculate the Covariance Matrix.
16. Compute Eigenvalues and Eigenvectors of the Covariance Matrix.

## 📊 Key Concepts Covered
- Vectors and Vector Norms
- Dot Product and Cross Product
- Matrix Addition and Multiplication
- Matrix Transpose, Inverse, and Determinant
- Linear Transformations
- 2D and 3D Geometry
- Dimensionality and Hyperplanes
- Covariance Matrix
- Eigenvalues and Eigenvectors
